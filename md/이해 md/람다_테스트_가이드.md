# AWS Lambda 상세 테스트 가이드 (Step-by-Step)

이 가이드는 `ranking.py`와 `high_score_lambda.py`(또는 `web_mypage.py`)를 **AWS 콘솔**에서 확실하게 테스트하는 방법을 단계별로 설명합니다.
* high_socre_lambda.py : 전체 랭킹 조회
* web_mypage.py : 내 랭킹 조회 

---

## 1. 사전 준비 (AWS 콘솔 접속)
1. AWS Management Console에 로그인합니다.
2. 상단 검색창에 **Lambda**를 입력하고 선택합니다.
3. 함수 목록에서 테스트하고 싶은 함수 이름을 클릭합니다.
    *   예: `high_score_lambda-dev` (Ranking 관련 람다)
    *   또는 `web-mypage-dev` (MyPage 관련 람다)

---

## 2. 테스트 이벤트 생성 및 실행

### Case A: 전체 랭킹 조회 테스트 (Global Ranking)

1. **[Test]** 탭(또는 주황색 Test 버튼)을 클릭합니다.
2. **Test event action**에서 **Create new event**를 선택합니다.
3. **Event name**에 `TestGlobalRanking`이라고 입력합니다.
4. 아래 **Event JSON** 편집창에 다음 코드를 **그대로 복사해서 붙여넣습니다**:
    *   (수정됨) **email** 필드를 추가했습니다.
    ```json
    {
      "body": "{\"action\": \"get_ranking\", \"email\": \"test@test.com\"}",
      "resource": "/ranking",
      "path": "/ranking",
      "httpMethod": "POST",
      "queryStringParameters": null,
      "headers": {
        "Content-Type": "application/json"
      }
    }
    ```

### Case B: 내 랭킹 조회 테스트 (My Rank)
*`api.js`의 `getMyRank` 함수 테스트 (`{ "action": "get_my_rank", "user_id": "..." }`)*

1. 다시 **[Test]** 탭으로 갑니다.
2. **Create new event**를 선택합니다.
3. **Event name**에 `TestMyRank`라고 입력합니다.
4. **Event JSON**에 다음을 입력합니다 (**본인의 실제 이메일이나 테스트용 ID로 변경하세요**):
    *   (수정됨) `body` 안에 `email`을 추가했습니다.
    ```json
    {
      "body": "{\"action\": \"get_my_rank\", \"email\": \"kimujin24@gmail.com\"}",
      "resource": "/ranking",
      "path": "/ranking",
      "httpMethod": "POST",
      "queryStringParameters": null,
      "headers": {
        "Content-Type": "application/json"
      }
    }
    ```
    *(마찬가지로 Proxy 통합이 아니라면 body 내용인 `{"action":..., "user_id":...}` 만 JSON으로 넣습니다)*

5. **[Save]** 후 **[Test]** 클릭.
6. 결과에서 `rank`와 `score` 등이 나오는지 확인합니다.

## 3. 자주 발생하는 오류 해결 (Troubleshooting)

### Q1. "KeyError: 'body'" 라는 에러가 떠요!
*   **원인**: 람다 코드가 `event['body']`를 찾는데, 테스트 이벤트 JSON에 `body` 필드가 없어서 그렇습니다.
*   **해결**: 위 **Case A/B**의 첫 번째 JSON 형식(API Gateway Proxy 스타일)을 사용해야 합니다.

### Q2. "KeyError: 'action'" 라는 에러가 떠요!
*   **원인**: 람다 코드가 `event['action']`을 바로 찾는데, JSON이 너무 복잡하게 되어있거나(Proxy 스타일), 반대로 `body` 안에 담겨있는데 파싱을 안 해서 그렇습니다.
*   **해결**:
    *   만약 코드가 `json.loads(event['body'])`를 한다면 -> **Case A**의 첫 번째 JSON 유지.
    *   만약 코드가 `event['action']`을 바로 쓴다면 -> 아래처럼 단순하게 수정해서 테스트하세요:
        ```json
        {
          "action": "get_ranking"
        }
        ```

### Q3. "Task timed out"이 떠요!
*   **원인**: 람다가 3초(기본값) 안에 처리를 못 끝냈습니다. (DB 연결 지연 등)
*   **해결**: [Configuration] 탭 > [General configuration] > [Edit] > **Timeout**을 10초 정도로 늘려주세요.

### 2.3 Case C: 마이페이지 정보 조회 (web_mypage.py)
